# Thomas Le Personal Website

This repository contains my personal portfolio website.

It is a custom site built to share a bit about me, highlight my experience and projects, and provide an easy way to get in touch.

## Built With

- Next.js
- React
- TypeScript
- CSS Modules

## Sections

- Home
- About
- Experience
- Projects
- Hobbies
- Contact

## Running Locally

```bash
npm run dev
```

Then open `http://localhost:3000`.
